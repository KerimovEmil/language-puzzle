# Language Puzzle Explanations

## Puzzle 1 — four

Each picture's English name sounds like the word for "four" in that language:

| Image | Language | Word | Sounds like |
|---|---|---|---|
| Cat | French | quatre | "cat" |
| Charizard | Urdu | چار (chaar) | "char" |
| Death | Chinese | 四 (sì) | 死 (sǐ, death) |
| Dirt | Turkish | dört | "dirt" |
| Foreman | English | four | "fore" |
| Net | Korean | 넷 (net) | "net" |

## Puzzle 2 — eggplant

| Clue | Language | Word |

| almond | Turkish / Azeri | badımcan |
| melon | Latin / Austrian / Italian | melanzani |
| Auber + jeans | British / German / French | aubergine |
| blue tomato | Macedonian | модар патлиџан |
